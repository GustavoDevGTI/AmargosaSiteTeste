# Construtor visual — Portal de Amargosa

Protótipo navegável do construtor de portais municipais, com identidade visual
de Amargosa e validação PNTP apresentada durante a edição.

## O que já pode ser testado

- edição de título e descrição em tempo real;
- variantes, alinhamento e densidade do destaque;
- prévias para desktop, tablet e celular;
- estrutura de blocos protegidos, restritos e opcionais;
- biblioteca homologada de componentes;
- checklist PNTP e simulação de bloqueio de publicação.

## Requisitos

- Node.js 22.13 ou superior;
- npm.

## Executar localmente

```bash
npm install
npm run preview:share
```

Abra o endereço `Local` exibido no terminal. Para testar em outro computador
na mesma rede, use o endereço `Network`.

## Validar a compilação

```bash
npm run build
```

O projeto é um rascunho funcional para experimentação do construtor. A
estimativa PNTP exibida na interface é demonstrativa e não representa
certificação oficial.
